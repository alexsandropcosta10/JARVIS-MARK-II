PRONTO

Quando perceber que entrou no piloto automático, use este roteiro para voltar a escolher sua próxima ação.

  1. Pausar. Interrompa por um instante.
  2. Identificar. O que está acontecendo: tédio, ansiedade, vontade ou distração?
  3. Separar. Um impulso é uma sensação, não uma ordem.
  4. Redirecionar. Mude de ambiente ou escolha uma alternativa segura.
  5. Retomar. Faça uma tarefa pequena por dois minutos.

Como funciona o XP?

XP é um registro de ações concluídas. Ele ajuda a visualizar consistência, não mede seu valor pessoal.

  • Conclua uma missão para receber o XP definido.
  • A cada 100 XP, você sobe um nível.
  • Missões secundárias são opcionais.
